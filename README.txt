Погружаясь в грёзы — мини-сайт

Файлы:
- index.html — страница плеера
- cover.png — обложка
- track.mp3 — аудиозапись

Плеер по умолчанию начинает с громкости 25%. Ползунок позволяет менять громкость от 0 до 100%.

Для публикации на GitHub Pages загрузите все файлы и папку проекта в репозиторий, затем включите Pages в Settings → Pages.

Примечание: если публикуете аудиозапись в интернете, убедитесь, что у вас есть необходимые права на её размещение.

Зацикливание: аудио подготовлено с 5-секундным кроссфейдом на стыке и автоматически повторяется в плеере. Переход сделан для максимально незаметного повтора, но восприятие зависит от музыкальной фразы.
